# 💰 DT Money — Exercício de Matemática Básica para Programação

Este projeto foi desenvolvido como parte da aula prática de **Matemática Básica voltada à Programação** no curso de Desenvolvimento Web da UFG. O objetivo era reproduzir o layout apresentado pelo professor com o máximo de fidelidade, aplicando os conceitos de **HTML** e **CSS** ensinados em sala.

> ⚠️ Spoiler: o professor não pediu JavaScript, mas como já tenho experiência, resolvi dar uma turbinada no projeto por conta própria 😎

---

## 🎯 Objetivos do Exercício

- Reproduzir a interface de uma aplicação de controle financeiro chamada **DT Money**
- Aplicar técnicas de estruturação semântica com HTML
- Utilizar estilos modernos com CSS, incluindo:
  - Flexbox
  - Responsividade
  - Botões interativos
  - Modal customizado
- Organizar o layout de forma clara e funcional, com foco em usabilidade

---

## 🧠 Funcionalidades Extras (JS por conta própria)

Embora não fosse exigido, o projeto inclui funcionalidades JavaScript para tornar a aplicação interativa:

- **Modal de Nova Transação**: abre ao clicar no botão "Nova transação"
- **Cadastro de Transações**: adiciona novas entradas ou saídas à tabela
- **Classificação de tipo**: botões para selecionar "Entrada" ou "Saída"
- **Atualização dinâmica da tabela**: sem recarregar a página

---

## 📱 Responsividade

A interface foi cuidadosamente ajustada para funcionar bem em dispositivos móveis, com:

- Layout flexível
- Inputs e botões adaptados
- Modal compacto e legível
